API 문서

v1.0 REST API
📚 컴북스 도서 데이터 API

스크래핑된 도서 정보와 표지 이미지를 다른 웹사이트에서 활용할 수 있도록 제공하는 REST API입니다. 모든 응답은 JSON 형태로 제공되며, CORS가 활성화되어 있어 브라우저에서 직접 호출 가능합니다.

Base URL: {{ request.host_url }}api/
GET /api/books

전체 도서 목록을 페이지네이션과 함께 반환합니다.

파라미터:
  • page (선택): 페이지 번호 (기본값: 1)
  • per_page (선택): 페이지당 항목 수 (기본값: 20, 최대: 100)
  • series (선택): 시리즈명으로 필터링
예시:
GET {{ request.host_url }}api/books?page=1&per_page=10&series=인공지능총서
GET /api/books/{book_id}

특정 도서의 상세 정보를 반환합니다. 강의안과 PDF 첨부파일 정보도 포함됩니다.

예시:
GET {{ request.host_url }}api/books/1
GET /api/series

모든 도서 시리즈 목록과 각 시리즈별 도서 수를 반환합니다.

예시:
GET {{ request.host_url }}api/series
GET /api/search

제목, 저자, 설명, 목차에서 키워드를 검색합니다.

파라미터:
  • q (필수): 검색 키워드
  • page (선택): 페이지 번호 (기본값: 1)
  • per_page (선택): 페이지당 항목 수 (기본값: 20, 최대: 100)
예시:
GET {{ request.host_url }}api/search?q=인공지능&page=1
GET /api/stats

전체 통계 정보를 반환합니다.

예시:
GET {{ request.host_url }}api/stats
💡 JavaScript 사용 예시
// 전체 도서 목록 가져오기
fetch('{{ request.host_url }}api/books')
  .then(response => response.json())
  .then(data => {
    console.log('총 도서 수:', data.pagination.total);
    data.books.forEach(book => {
      console.log(book.title, book.author);
    });
  });

// 특정 도서 상세 정보 가져오기
fetch('{{ request.host_url }}api/books/1')
  .then(response => response.json())
  .then(book => {
    console.log('도서명:', book.title);
    console.log('표지 이미지:', book.cover_image_url);
    console.log('강의안 있음:', book.lecture_plan ? '예' : '아니오');
  });

// 도서 검색
fetch('{{ request.host_url }}api/search?q=인공지능')
  .then(response => response.json())
  .then(data => {
    console.log('검색 결과:', data.books.length + '권');
  });
